# Sakura Lab

Sakura Lab es una tienda de regalos personalizados que fusiona artesanía y tecnología. ofrece servicios de impresión 3D, tazas sublimadas y corte láser de alta precisión, transformando conceptos técnicos en realidades tangibles y detalles que florecen.  

Sakura Lab, dirigido por Angela Gonzalez. Especialistas en impresión 3D, tazas sublimadas y corte láser en Santa Elena, Ecuador. Realizamos envíos a todo el Ecuador .

## Panel de administración

El panel de Keystatic tiene dos modos:

- `npm.cmd run dev`: modo local, sin autenticación, pensado únicamente para editar desde la computadora del desarrollador.
- `npm.cmd run dev:github`: modo GitHub, solicita autenticación y permisos de escritura en el repositorio configurado.

Para probar el segundo modo localmente:

1. Crea una GitHub App desde `/keystatic` cuando aparezca el asistente.
2. Instálala únicamente en `DavidParragaMendoza/SakuraLab`.
3. Crea `.env.github` con las variables que entrega Keystatic:

   ```text
   KEYSTATIC_GITHUB_CLIENT_ID=...
   KEYSTATIC_GITHUB_CLIENT_SECRET=...
   KEYSTATIC_SECRET=...
   PUBLIC_KEYSTATIC_GITHUB_APP_SLUG=...
   ```

4. Ejecuta `npm.cmd run dev:github` y abre `http://localhost:4321/keystatic`.

La URL de callback local es:
`http://localhost:4321/api/keystatic/github/oauth/callback`

No compartas ni subas `.env.github`; contiene credenciales privadas.
